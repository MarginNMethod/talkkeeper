# Security policy

The project is an early scaffold. Only the latest default-branch revision receives
security fixes; there is no production support guarantee yet.

Please use this repository's private vulnerability reporting feature to report a
suspected vulnerability. If that feature is unavailable, ask maintainers to enable
a private reporting channel in an issue without posting exploit details or secrets.
Include affected revisions, a minimal reproduction with synthetic data, expected
impact, and any proposed fix. Never attach real meeting content or API keys.

Maintainers will acknowledge reports as capacity permits, coordinate a fix and
publication with the reporter, and avoid exposing sensitive meeting data. There is
no guaranteed response deadline at this stage.
